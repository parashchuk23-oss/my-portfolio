# My Portfolio

Навчальний проєкт персонального портфоліо. Сторінка містить ім’я, коротку інформацію про автора, перелік навичок і контактні дані. Дизайн адаптується до екранів мобільних пристроїв.

## Поточна версія

Робоча версія містить адаптивну картку профілю, секцію навичок і посилання на контакти. Цей стан збережено перед додаванням нової інтерактивної функції.

## Використані технології

- HTML5
- CSS3
- JavaScript
- Git

## Нова функціональність

На сторінці додано перемикач світлої та темної теми. Обрана тема зберігається в `localStorage`, тому налаштування не втрачається після перезавантаження сторінки. Якщо користувач ще не обрав тему, сайт враховує системне налаштування браузера.

## Запуск проєкту

1. Завантажте або клонуйте репозиторій.
2. Відкрийте папку проєкту.
3. Відкрийте файл `index.html` у браузері.

Додаткові залежності та встановлення пакетів не потрібні.
